# BookTalk

**BookTalk** er et 'sosialt-nettverks'-basert bok-anmeldelses system hvor brukere kan *anmelde* bøker som de har lest (ved å sette på 1-5 stjerner og et *valgfritt beskrivelse* av anmeldelsen), og hvor andre brukere kan også *kommentere* på anmeldelsene. BookTalk er inspirert av letterboxd.

## Teknologier brukt

- VSCodium (telemetri-fritt versjon av Visual Studio Code)
  - Extensions: Live Server, Prettier, Error Lens, Python
